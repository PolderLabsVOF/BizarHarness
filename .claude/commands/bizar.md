# Bizar Harness

Use `/bizar` to orient a task to the installed Claude Code-native harness.

1. Read `PROGRESS.md`, `feature_list.json`, and the repository instructions.
2. Select the smallest appropriate lane: direct execution, research, plan/audit, team, or guarded background work.
3. State the target result, constraints, validation evidence, and stop condition.
4. Use `bizar --help` for CLI primitives and the installed skills for workflow-specific instructions.
5. Preserve human approval gates for destructive, publishing, deployment, and credential-sensitive operations.

Bizar has no browser control plane or persistent web service. Project files, Claude Code hooks, MCP tools, and CLI output are the operational surfaces.
