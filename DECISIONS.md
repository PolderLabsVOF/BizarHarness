| F-191 | Land the append-only `DispatchEvidence` store (`packages/sdk/src/router/dispatch-evidence.ts`) as the durable audit trail between the F-188 `ModelDecision` and the post-dispatch outcome. The store writes rows via `fs.open(path, 'a')` + `fsync()` so partial writes cannot corrupt the log; each row carries `schemaVersion: 1`, server-stamped `createdAt`, and SHA-256 input-fingerprint hashes of `selectedProfiles` / `staticProfiles` / `activeSessionModel` / `budget` / `health`. The store exposes `createFileEvidenceStore(path)`, `createInMemoryEvidenceStore()`, `record({ decision, taskFeatures, inputs, runId, agentName, workflowPhase })`, and `attachOutcome(decisionId, outcome)`. `attachOutcome` is exactly-once: re-attaching with the canonical-identical outcome is idempotent (returns the existing row); re-attaching with a different outcome throws `OutcomeConflictError`. A duplicate `routingDecisionId` is rejected with `DuplicateEvidenceError`. Disk failures (`EACCES`, `ENOSPC`) surface as `EvidenceStoreError`. Thread an optional `evidenceStore?: EvidenceStore` parameter through `packages/sdk/src/router/select-dispatch-model.ts#selectDispatchModel` and `packages/sdk/src/router/failover.ts#pickFailover` so every primary dispatch and every failover follow-up writes a row chained by `routingDecisionId` + monotonic `sequence` (0 for primary, ≥1 for follow-up). `pickFailover` writes `sequence: 1` follow-up rows carrying the original `routingDecisionId` and a `failoverFrom: [originalId]` field. `router/index.ts#decideAgentWith` accepts the store and threads it. `config/workflows/lib/dispatch.js` records the outcome under `verifiedBy: 'review-bot'` on every returned agent. Ship the CLI `bizar evidence {tail,show,verify,run,audit}` subcommands (`cli/commands/evidence.mjs`) — `verify` walks the chain and checks every SHA-256 fingerprint, `audit` surfaces rows where `outcome` is missing or status is non-`success`. Tests: `packages/sdk/tests/dispatch-evidence.test.mjs` (6 cases: append-only integrity, exactly-once, idempotent outcome, conflict surface, sha-256 fingerprint stability, sha fingerprint mutation rejection), `packages/sdk/tests/select-dispatch-model-evidence.test.mjs` (6 cases pinning the evidence threading through `selectDispatchModel`), `scripts/__tests__/dispatch-evidence-drift.test.mjs` (5 cases failing CI when `evidenceStore` or any append-call is removed from `selectDispatchModel` or `pickFailover`), and `cli/__tests__/evidence.test.mjs` driving the CLI subcommands. Closes IMP-018; supersedes the pre-F-191 "evidence lives wherever the caller remembers" pattern. | Accepted |
