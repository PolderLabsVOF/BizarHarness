| F-184 | Land a userSelected-aware resolver (`packages/sdk/src/router/agent-model-registry.ts#rankUserSelectedForRole`) that ranks the operator-selected pool by capability profile before falling back to the tier default. Precedence: userSelected pool → tier default → inherit session. Capability score weights reasoning=0.3, toolCall=0.25, structuredOutput=0.15, attachment=0.1, temperature=0.05, +0.15 for image input. Eligibility floors (minContextTokens, requireReasoning/ToolCall/StructuredOutput/ImageInput, preferredTiers) surface human-readable `ineligibleReasons`. `parseUserSelected` reads `userSelected.profiles` defensively (silently skips invalid entries). `defaultTierHintForId` mirrors the picker heuristic. Closes IMP-016; IMP-019 (health-aware failover) deferred. | Accepted |
| F-185 | Land the health-aware selected-pool failover walker (`packages/sdk/src/router/failover.ts#pickFailover`) that consumes the F-184 ranking and picks the next eligible user-selected ID for a transport/availability failure (`invalid-model`, `auth-failure`, `rate-limit`, `timeout`, `provider-outage`); non-transport failures (`context-overflow`, `model-quality`) skip failover. Hard cap is one failover attempt — never alias-cycle, never re-try the same failed request, never walk past the first eligible ranked ID. Returns a `FailoverVerdict` audit trail (primary, failover, attempts, exhaustReason, chain) so the orchestrator and telemetry can record every step. `Agent-model-guard.mjs` accepts `additionalContext.routingDecisionId` + `additionalContext.fallback` without re-probing the gateway when both are set (both-or-neither contract); existing callers see no behavior change. `bizar models explain <role>` ranks the persisted user-selected pool without touching the gateway. `failover-mirror.mjs` keeps the CLI ranking byte-identical to the SDK so divergence fails the test gate. `classifyError` maps wire-level messages to the `FailureReason` taxonomy. Closes IMP-019. | Accepted |
| [F-186](docs/decisions/AUTONOMY_CONTRACT.md) | Single canonical `AUTONOMY_CONTRACT.md` under `docs/decisions/` enumerates four tiers (Tier 1 full autonomy, Tier 2 advisory allow+🟡, Tier 3 HitL via `permission-request.mjs` + `git-workflow-guard.mjs`, Tier 4 blocked at the hook layer), declares the settings template contract (`permissions.deny: []`, `permissions.ask: []`, `defaultMode: "bypassPermissions"`, `permissions.allow` covers Tier 1), and cross-references every enforcement surface. `scripts/__tests__/autonomy-contract.test.mjs` asserts settings shape, Tier-1 allow coverage, hard-deny floor in `permission-request.mjs`, advisory pattern enumeration across `pretooluse-bash` / `pretooluse-editwrite` / `git-workflow-guard`, commit-time secret guard (`.env` / `.envrc` / `secrets/` / `credentials/` / `*.pem` / `*.key`), and the cross-reference list. Closes IMP-001; supersedes drift between the settings template, the hook chain, the orchestrator prompt, and `AGENTS.md`. | Accepted |
| F-187 | Land the canonical 6-tier `BizarTier` taxonomy (`premium` / `high` / `mid-design` / `default` / `mid` / `budget`, exported by `packages/sdk/src/router/agent-model-registry.ts#BizarTier`) across `packages/sdk/src/router/model-router.ts` and `packages/sdk/src/router/index.ts`. Drop the legacy 3-tier `ModelTier` alias (`flash` / `mid` / `expensive`); codemod short-circuit returns `tier="budget"` and `recordOutcome()` switches from a 3-way ternary to a per-tier `REWARDS` map (budget 1.0, mid/default 0.85, mid-design 0.7, high 0.55, premium 0.4). Both router test files rewrite literals (flash→budget, expensive→premium, mid unchanged) and the model-router suite gains three new tests pinning high's default prior and the per-tier reward increments. Add `packages/sdk/tests/tier-taxonomy-drift.test.mjs` (4 vitest cases) as the IMP-015 acceptance test: it scans `packages/sdk/src/` for `ModelTier` declarations, `"flash"` / `"expensive"` string literals, and `ModelTier` TypeScript identifiers, and fails CI on the first reintroduction of the legacy vocabulary. Closes IMP-015; supersedes the 3-tier Thompson-sampling bandit vocabulary. | Accepted |
