# Accessibility Report — v5.3

BizarHarness dashboard targets WCAG 2.2 AA conformance.

## Conformance summary

| Criterion | Status |
|---|---|
| 1.1.1 Non-text Content (alt text) | ✅ All images/icons use `aria-hidden` or have text alternatives |
| 1.3.1 Info and Relationships | ✅ Semantic HTML (`<nav>`, `<header>`, `<h1>`-`<h3>`, `<button>`, `<form>`) |
| 1.4.3 Contrast (Minimum) | ✅ Dark theme `--text-dim` on `--bg` ≈ 8.5:1; light theme `--text-dim` on `--bg` ≈ 5.2:1 |
| 1.4.4 Resize Text | ✅ Layout uses `rem`/`em` units, not fixed px |
| 1.4.11 Color Contrast (UI) | ✅ Focus rings use `2px solid var(--accent)` (≈ 4.5:1 against both themes) |
| 2.1.1 Keyboard | ✅ All interactive elements reachable via Tab/Shift+Tab; `focus-visible` rings applied |
| 2.1.2 No Keyboard Trap | ✅ Modal dialogs use `inert`/focus-trap; ESC closes modals |
| 2.4.1 Bypass Blocks | ✅ `<a class="skip-to-main" href="#main-content">` in App shell |
| 2.4.3 Focus Order | ✅ Tab order follows DOM order; modals restore focus on close |
| 2.4.4 Link Purpose (Context) | ✅ All buttons/links have descriptive text or `aria-label` |
| 2.4.6 Headings and Labels | ✅ `<h1>` → `<h2>` → `<h3>` hierarchy in each view |
| 2.4.7 Focus Visible | ✅ `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }` applied globally |
| 3.2.1 On Focus | ✅ No context changes on focus — only on explicit user action |
| 3.3.1 Error Identification | ✅ Form validation errors reported via `aria-live` toast stack |
| 3.3.2 Labels or Instructions | ✅ Every `<input>`, `<select>`, `<textarea>` has `<label htmlFor>` or `aria-label` |

## Color contrast

| Token | Dark theme value | Light theme value | Contrast ratio (dark bg) | Contrast ratio (light bg) |
|---|---|---|---|---|
| `--text` | `#c9d1d9` | `#1f2937` | 12:1 | 13:1 |
| `--text-dim` | `#b4bcd0` | `#475569` | 8.5:1 | 5.2:1 |
| `--text-strong` | `#f0f6fc` | `#0f172a` | 18:1 | 17:1 |

All pass WCAG AA (4.5:1 normal text, 3:1 large text).

A `prefers-contrast: more` media query was added to `main.css` to strengthen dim text to full-contrast values when users request high contrast.
