# Release Notes — `@polderlabs/bizar-plugin@0.5.4`

**Date:** 2026-06-18
**Tag:** `v0.5.4` (plugin)
**Companion CLI release:** `@polderlabs/bizar@2.3.0`

## TL;DR

Companion release to the v2.3.0 CLI rename. The plugin's npm package is now `@polderlabs/bizar-plugin` (was `@polderlabs/bizarharness-plugin`). All default cache paths are now `~/.cache/bizar/` (was `~/.cache/bizarharness/`).

## What's in 0.5.4

### Renamed npm package

`@polderlabs/bizarharness-plugin` → `@polderlabs/bizar-plugin`. The plugin directory on disk remains `~/.config/opencode/plugins/bizar/` — only the npm name changed.

### Renamed default cache paths

| Old (v0.5.3 and earlier) | New (v0.5.4) |
|---|---|
| `~/.cache/bizarharness/logs/` | `~/.cache/bizar/logs/` |
| `~/.cache/bizarharness/` (state dir) | `~/.cache/bizar/` |
| `~/.cache/bizarharness/bg/<instanceId>.json` | `~/.cache/bizar/bg/<instanceId>.json` |
| `~/.cache/bizarharness/plan-settings.json` | `~/.cache/bizar/plan-settings.json` |

The rename is a **clean break** — no migration script. The plugin reads/writes only the new path. Old files at the old path are orphaned but harmless; you can delete them with `rm -rf ~/.cache/bizarharness`.

### Other changes

- All in-repo references in source, tests, README, and comments use the new names.
- Bundled skill `bizarharness` (folder at `~/.opencode/skills/bizarharness/`) is now `bizar`. The `install.sh` script copies the renamed folder.
- Version test (`config.test.ts`) updated to pin against the new version.

## What's not in 0.5.4

- **No new functionality.** The plugin's behavior is identical to v0.5.3 — same loop-guard thresholds, same background agents, same plan canvas, same tools. The only changes are naming.
- **The plugin's runtime config (opencode.json `plugin` array) is unchanged.** Users do not need to update their `opencode.json` — the plugin is still loaded from `~/.config/opencode/plugins/bizar/index.ts`.

## Upgrade from `@polderlabs/bizarharness-plugin`

```bash
# 1. Install the new package
npm install -g @polderlabs/bizar-plugin

# 2. The install script will re-deploy the plugin source to
#    ~/.config/opencode/plugins/bizar/. Run it from the BizarHarness repo:
cd /path/to/BizarHarness
./install.sh

# 3. Restart opencode (no hot-reload — see Bizar-Plugin wiki §limitations).

# 4. (Optional) Uninstall the old package
npm uninstall -g @polderlabs/bizarharness-plugin

# 5. (Optional) Remove the old cache directory
rm -rf ~/.cache/bizarharness
```

Or, if you have the v2.3.0 CLI installed, just run `bizar update` and it will do steps 1–3 for you.
