# Release Notes — `@polderlabs/bizar@7.0.0`

**Date:** 2026-07-12
**Tag:** `v7.0.0`
**Status:** MAJOR — dashboard redesign + carried v6.5.0 work

## TL;DR

v7.0.0 lands the F-040 dashboard redesign: a custom `ui/` design
system under `bizar-dash/src/web/ui/` (controls, data, feedback,
layout, navigation, primitives, theme, tokens) plus three view
rewrites (Overview, Agents, Tasks). It also carries the v6.5.0
work (F-037 migration gap cleanup, F-038 federation skeleton,
F-039 Byzantine consensus) that had been prepared but not
published.

> **Honest scope note:** the *infrastructure* for live agent
> status and history (REST API, agents-store with on-disk
> persistence, WebSocket broadcast, 11 `/api/agents/*` endpoints,
> `/api/history` aggregator) is fully present and exercised by
> the UI. The *hook-driven auto-feed* — hooks that POST to
> `/api/agents/:name/status` as Claude Code tools fire — is **not**
> wired in this release. That was the deferred PR #2. Until that
> lands, agents show "idle" by default; the Agents and History
> views surface data from manual `status` POSTs and CLI
> operations, not from the live Claude Code session loop.

## Notes for contributors

### New design system

Mod authors: the legacy `styles/main.css` is auto-merged but the
new design system is at `bizar-dash/src/web/ui/`. New mods should
import from the design system, not hand-roll CSS. See
`docs/dashboard-ui-migration.md` for the mapping.

### Agent data plumbing

To push status updates from anywhere in v7.0.0, POST to:

```
POST /api/agents/:name/status
{ "status": "idle|working|error|stuck", "currentTaskId": "..." }
POST /api/agents/:name/heartbeat
```

The `agents-store` persists to `~/.config/bizar/agent-status.json`
and the route broadcasts `agents:change` on the WebSocket. The
`Agents` view re-renders on the next snapshot poll.

### Federation + consensus

`@polderlabs/bizar-sdk@0.5.0` exposes the federation and consensus
modules. See `packages/sdk/src/federation/index.ts` and
`packages/sdk/src/consensus/index.ts` for the public surface, and
`docs/decisions/` for the design records.
