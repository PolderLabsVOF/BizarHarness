# v3.4.0 — UI Overhaul

**Slug:** v3-4-0-ui-overhaul · **Status:** In-Progress · **Author:** drb0rk · **Created:** 2026-06-19

---

## Overview

Comprehensive UI overhaul for v3.4.0. Resolves the pervasive theme bug
(sidebar text + drop shadows not reacting to theme), makes the Config page
properly editable (providers + MCPs), puts the Tasks kanban on one row with
a compact toolbar, replaces the Activity graph-only canvas with a real
time-based timeline, removes the Overview textbox card wrapper in favor of
a hero gradient title, and adds a cross-project History view.

## Goals

- [x] F1 — All hardcoded colors (sidebar text, drop shadows, badges, focus rings) respond to theme change
- [x] F2 — Config page: sidebar nav + fully editable providers + MCPs (with remote MCP support)
- [x] F3 — Tasks kanban: 4 columns side-by-side with horizontal scroll on narrow screens
- [x] F4 — Tasks toolbar: compact single-row layout (search + filter + sort + actions)
- [x] F5 — Activity: visual timeline canvas (X=time, Y=agent) with event detail tooltip
- [x] F6 — Overview: huge textarea, gradient title, no card wrapper
- [x] F7 — History view: per-project timelines with time range filter + JSON export
- [x] F8 — Config page sidebar nav (OpenCode / Providers / MCPs / Diagnostics / Export)
- [x] F9 — Visual plan tracking (this plan)

## Non-Goals

- Server-side import (only export for now)
- Per-project activity log streams (we aggregate the global log)
- Plan UI redesign (skipped — not in scope)

## Background

The user reported that:
- Sidebar text doesn't update when theme changes
- Drop shadow on the Overview hero doesn't update on theme change
- Config page Providers tab is empty + not editable
- Tasks kanban columns wrap onto multiple rows
- Tasks sort/filter selectors feel oversized
- Activity canvas shows static agents/tasks/bg but no timeline of what was done
- Overview textbox should be the dominant element on the page, not hidden in a card

## Detailed Plan

### Phase 1: Theme tokens (F1)

Add `--accent-glow`, `--accent-soft`, `--success-soft`, `--error-soft`,
`--warning-soft`, `--overlay-bg`, `--shadow-color-strong` to both `:root`
and `[data-theme='light']`. Replace remaining hardcoded `rgba(...)` values
across `main.css`. Audit `.sidebar-tab` (already uses `--text-dim` /
`--text` / `--accent-2`), `.brand-*`, modal backdrop, status pills, etc.

### Phase 2: Config page overhaul (F2 + F8)

Rewrite `Config.tsx` with a two-column layout:
- Left: `config-nav` (OpenCode / Providers / MCPs / Diagnostics / Export)
- Right: content panel that swaps based on selected section

Providers and MCPs panels get full edit/delete/toggle/enable via modal
forms. `mcpsStore` extended to handle the new `opencode.json#mcp` format
(array `command`, `type: remote`, `url`, `headers`, `oauth`).

### Phase 3: Tasks kanban + toolbar (F3 + F4)

`.kanban` grid template changes to `repeat(4, minmax(260px, 1fr))` with
horizontal scroll fallback. Header actions move into a compact
`.tasks-toolbar` single-row layout with grouped Search / Filter / Sort
labels.

### Phase 4: Activity timeline (F5)

`Activity.tsx` gains a `mode` toggle (Graph / Timeline). The new
`TimelineView` component renders SVG lanes (one per agent + system +
plans + bg), time axis, event circles colored by kind, hover tooltips,
kind filter, and zoom controls. Click event → opens the corresponding
node detail panel.

### Phase 5: Overview hero (F6)

Replace the `.overview-hero` card with `.overview-hero-noframe`. H1 gets a
48px gradient title. Textarea uses `.overview-input-hero` (160px min,
rounded, glow focus ring). Quick action chips in a row.

### Phase 6: History view (F7)

New `/api/history` endpoint aggregates activity log + per-project task
counts + plan counts. New `History.tsx` view with time range filter,
expandable per-project timelines, and JSON export. New "History" tab in
the Topbar.

### Phase 7: Verification + commit

`npx tsc --noEmit` for type check. `npm run build` for build. Existing
test suite for regression. Bump version 3.3.3 → 3.4.0 in
`package.json`, `bizar-dash/package.json`, `App.tsx`, `api.mjs` default
settings, `diagnostics-store.mjs`. Update `CHANGELOG.md`. Commit on
master without push.
